Automatic GPU inference setup

Detecting your graphics hardware and local inference binaries…

Grand Council downloads verified official llama.cpp binaries automatically. It prefers CUDA 12 for compatible NVIDIA cards, falls back to Vulkan, then CPU. No CUDA toolkit, compiler, PyTorch, or pip installation needed for GGUF models. Setup occurs on this machine after you click the button, or automatically when loading your first GGUF model.

Advanced Python runtimes (developer installs only)

Safetensors models still require a compatible Transformers runtime or an external inference server. GGUF is the recommended desktop format for local GPU acceleration.
